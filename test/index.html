Old Hangul Webfont Test / 옛한글 웹폰트 시험

Each sample should appear as one composed syllable block per syllable. The check measures the width of each syllable: a composed syllable is one cell wide, and a tone mark adds less than half a cell. The numbers are widths at 100px: first one cell (the width of 가), then each syllable (tone marks after +).
각 음절이 한 덩어리로 모여 보이면 정상입니다. 판정은 음절 폭을 재서, 한 칸 폭이고 방점이 반 칸보다 좁으면 ✓, 풀려서 넓어지면 ✗로 표시합니다. 숫자는 100px 크기에서 잰 폭입니다. 처음 숫자가 한 칸('가'의 폭)이고, 이어서 음절마다의 폭입니다(방점은 + 뒤에 표시).

Vertical writing / 세로쓰기

Syllables should stand upright, and tone marks should sit beside the syllable (on its left) without taking a cell of their own. The samples are split so that it is clear which kind of character causes a problem. upright forces every character upright with CSS text-orientation: upright. The numbers are the heights of 랏 and 랏+tone mark at 100px; they should be equal.
음절은 똑바로 서 있어야 하고, 방점은 음절 옆(왼쪽)에 붙어 따로 한 칸을 차지하지 않아야 합니다. 어떤 글자가 문제를 일으키는지 알 수 있도록 예시를 나눴습니다. upright는 CSS text-orientation: upright로 모든 글자를 세운 것입니다. 숫자는 100px 크기에서 '랏'과 '랏+방점'의 세로 길이이며, 둘이 같아야 합니다.
